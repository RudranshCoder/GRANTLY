## 📖 About

Finding scholarships shouldn't be complicated, yet students often deal with:

- 🔀 Scholarship information scattered across dozens of websites
- 🧩 Confusing and inconsistent eligibility requirements
- ⏰ Missed deadlines
- 📂 Documents and applications spread across different places

**GRANTLY** brings the whole journey into one clean, student-focused experience. Discover relevant scholarships, see how your profile matches their requirements, save the ones you like, and track every application through to the end.

> **Track 1: Unified Scholarship Discovery & Management Platform**, built for the **Frontend Arena Hackathon**.

## ✨ Features

### 🔍 Discover
- **Scholarship Discovery:** browse opportunities through one centralized interface.
- **Smart Search & Filters:** narrow results by education level, location, benefits and more.
- **Scholarship Details:** see eligibility, benefits, deadlines and required documents at a glance.

### 🎯 Match
- **Eligibility Matching:** compare your academic and personal profile against published requirements.
- **Student Profile:** keep your academic details and preferences in one place.

### 📋 Manage
- **Saved Scholarships:** bookmark opportunities and come back to them later.
- **Application Tracker:** organize and monitor the progress of every application.
- **Personalized Dashboard:** see relevant scholarships, saved items, application progress and upcoming deadlines together.

## 🧭 How It Works

1. **Create your profile:** add your education level, background and preferences.
2. **Discover scholarships:** search, filter and see how well you match.
3. **Save and apply:** bookmark favourites and review documents and deadlines.
4. **Track progress:** manage every application from your dashboard.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (LTS recommended)
- npm
- [Git](https://git-scm.com/)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/RudranshCoder/GRANTLY.git

# 2. Move into the project folder
cd GRANTLY

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

Open the local URL shown in your terminal. It is usually `http://localhost:5173`.

### Available Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server with hot reload |
| `npm run build` | Create an optimized production build |
| `npm run preview` | Preview the production build locally |

## ⚠️ Important Notes

> [!NOTE]
> GRANTLY is a hackathon project. Scholarship records shown in the app are **demo data**. Eligibility matching is **informational only** and does not guarantee eligibility or selection. Always verify scholarship details through the official provider.
